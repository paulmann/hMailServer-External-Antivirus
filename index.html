hMailServer-External-Antivirus

Real antivirus inside the hMailServer pipeline

hMailServer external-virus scripts that wire Kaspersky and Windows Defender command-line scanners into the native antivirus pipeline, with documented exit codes.

What it does

  • Kaspersky avp.com and Windows Defender integrations
  • Exit codes documented so the server reacts correctly
  • Fits the built-in External Antivirus setting

Built with

PowerShell
